# 询价比价助手

面向海外项目工程采购的 AI 询价比价工具：工程部需求清单 → 澄清问题 → 询价包和询价单 → 询价邮件 → 收集报价 → 比价表 → 定标和历史价。

## 一期功能

| 模块 | 内容 |
| --- | --- |
| 账号与团队 | 公司注册、邮箱密码登录、管理员添加成员，数据按公司隔离 |
| 工程项目与采购需求 | 两级结构：工程项目（如一个别墅区、一座海水冷却站）下建采购需求（材料、分包、租赁、服务）；侧边栏“项目”下展开工程项目列表；采购需求可移到其他工程项目 |
| 当地材料标准 | 工程项目填写地点后，AI 联网识别当地的材料标准体系和认证要求（如沙特 SBC、SASO/SABER、NWC、SEC），用于澄清问题、拆分询价包和询价单的“Applicable Standards”；仅供参考 |
| 询价设置与模板 | 每个采购需求有自己的询价单编号规则、币种税率、付款条款、询价单 Excel 模板和邮件模板；新建时可以勾选沿用之前任何一个采购需求的设置（按工程项目分组）；同一前缀的编号在公司内顺延不重复 |
| 需求清单与澄清 | 上传 Excel / PDF / 扫描件，AI 提取物资项、判断材料类别，按“材料澄清参数清单”生成待确认问题；可点选或填写答案，导出问题清单 Excel。识别在服务器后台进行，用户可以离开页面，工作台显示进度；多工作表的文件先选要识别的工作表 |
| 技术规格书 | 一次上传多份带文字的 PDF。CSI 编号的规格书（“SECTION 32 14 13”或页脚“32 14 13 - 3”）按章节建立索引，其他格式按页建立索引；AI 按规范号或关键词找到原文回答问题、补充技术要求 |
| 合同台账 | 合同的金额、付款、交货和状态；AI 导入已有台账、导出 Excel；定标后自动生成“待签订”合同；工作台提醒待签订和逾期交货 |
| 系统设置 | 浅色/深色/跟随系统、主题色、强调色、字体大小、界面语言（按浏览器保存）；公司名称、邮件落款人、团队成员 |
| 询价包与询价单 | AI 按供应商类型分包，可移动、合并、改名；锁定后生成编号并冻结内容；按公司模板或默认格式导出询价单 Excel |
| 供应商库与推荐 | 用户自己的供应商通讯录：导入采购台账、供应商资源库、旧比价表（任意格式、多工作表，长文件分段并行识别），AI 整理出每家供应商供过的具体材料；按材料搜索时依次列出“供过这种材料”“供过同类材料”“可能能供”；收到的报价和定标自动记入；询价时据此推荐（默认 3 家合作过的 + 1 家新供应商）；可 AI 联网搜索新供应商 |
| 询价邮件 | 按邮件模板为每家供应商生成邮件，一键复制，标记已发送（一期从自己的邮箱发送） |
| 界面语言 | 联合国六种工作语言：中文、English、Français、Español、Русский、العربية（阿拉伯语为右到左排版）；按浏览器语言自动选择，可随时切换；AI 生成的问题、提示和风险说明使用当前语言 |
| 报价与比价 | 上传报价（Excel / PDF / 扫描件 / 图片），AI 对齐询价行、统一不含税价和计价单位；人工修改单价和折算系数并留痕；规则核对 + AI 风险审查；导出带公式的比价表 Excel；整单或分项定标 |

## 部署（Vercel + Neon，免费额度即可起步）

需要准备：GitHub 账号、[Vercel](https://vercel.com) 账号、[Neon](https://neon.tech) 账号，以及一个 AI 模型的 API Key：国内用户推荐[阿里云百炼](https://bailian.console.aliyun.com)（通义千问，支付宝付费），有海外付款方式也可以用 [Anthropic Claude](https://platform.claude.com)。

1. **代码放到 GitHub**：新建一个私有仓库，把本项目所有文件上传进去。
2. **建数据库**：在 Neon 新建项目，区域选离用户近的（中东用户可选欧洲区域）。复制连接串（`postgresql://...`，选带 `-pooler` 的那个）。
3. **导入到 Vercel**：Vercel → Add New → Project → 选择刚才的 GitHub 仓库。
4. **填环境变量**（Vercel 项目 → Settings → Environment Variables）：
   - `DATABASE_URL` = Neon 连接串
   - 用通义千问时填这 5 项：
     - `AI_PROVIDER` = `openai`
     - `AI_BASE_URL` = `https://dashscope.aliyuncs.com/compatible-mode/v1`
     - `AI_API_KEY` = 百炼控制台里创建的 API Key（`sk-` 开头）
     - `AI_MODEL` = `qwen-plus`（文字识别）
     - `AI_VISION_MODEL` = `qwen3-vl-plus`（扫描件和图片识别）
   - 用 Claude 时只填 `ANTHROPIC_API_KEY`（可选 `ANTHROPIC_MODEL`，默认 `claude-sonnet-5-5`）
   - 模型名称以百炼控制台“模型广场”里实际可用的为准，换模型只需改这两个变量，不用改代码。
5. **部署**：点 Deploy。首次访问时会自动建表。打开网址 → 注册公司账号即可使用。

以后改了代码，推送到 GitHub，Vercel 会自动重新部署。

### 限制说明

- Vercel 免费版单次请求最长 5 分钟、请求体最大 4.5 MB。程序已经做了处理：报价和清单在浏览器里先读取，扫描件压缩成图片后再发送，规格书分批上传。需求清单分段上传后，每一段在服务器上单独识别（各有 5 分钟），长清单也不会超时。
- 扫描版规格书暂不支持（需要文字版 PDF）。
- 二期：邮箱直连（SMTP 发信、自动收集回信）、推荐当地新供应商、比价表模板映射。

## 本地开发

```bash
npm install
cp .env.example .env.local   # 填 AI 模型的 Key；不填 DATABASE_URL 时使用内置数据库（.data 目录）
npm run dev                  # http://localhost:3000
```

修改数据库结构：编辑 `src/db/schema.ts` 后运行 `npm run db:generate`，生成的迁移文件在 `drizzle/`，启动时自动执行。

## 代码结构

```
src/
  app/(auth)/            登录、注册
  app/(app)/projects/    工程项目列表；采购需求页（需求与澄清、规格书、询价包、询价设置与模板）
  app/(app)/sites/       工程项目页（当地材料标准、采购需求列表、新建采购需求和选模板）
  app/(app)/packages/    询价单页（询价单、供应商与邮件、报价与比价）
  app/(app)/suppliers/   供应商库与历史采购导入
  app/(app)/contracts/   合同台账
  app/(app)/settings/    系统设置：外观、语言、公司、成员
  app/api/               接口（全部按公司做权限校验）
  db/                    数据库结构（Drizzle）与连接
  lib/ai.ts, prompts.ts  调用 AI 模型（Claude 或兼容 OpenAI 的国内模型）和提示词
  lib/checklist.ts       材料澄清参数清单（可持续扩充）
  lib/taxonomy.ts        材料分类（大类 → 类别，含关键词和相关类别，用于“供过同类”的联想）
  lib/materials.ts       供应商供过的材料：记录、按材料匹配供应商
  lib/demand.ts          需求清单后台识别（分段任务，after() 里执行，最后一段完成时合并保存）
  lib/settings.ts        采购需求的询价设置、模板、询价单编号顺延
  lib/specs.ts           规格书分章节/分页索引和关键词查找
  lib/compare.ts         比价计算与规则核对（前后端共用）
  lib/client/            浏览器端：文件读取（长清单分段并行识别）、Excel 生成
  lib/i18n/              界面语言：以中文原文为键，en/fr/es/ru/ar 各一份译文
  components/            界面组件（shadcn/ui 风格 + Tailwind CSS）
```
